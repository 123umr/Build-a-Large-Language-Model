练习 2.1 未知单词的 BPE 
尝试使用 tiktoken 库中的 BPE 分词器对未知单词“Akwirw ier”进行分词，并打印所有 
词元 ID。然后，对得到的列表中的每个整数应用 decode 函数，以重现图 2-11 中的映射。最 
后，对这些词元 ID 调用 decode 方法，检查它能否还原原始输入“Akwirw ier”

1. 汉字在 UTF-8 里占 3 个字节 ，比如`我` =`E6 88 91` 。
2. GPT-2 用的是 byte-level BPE ：基础词表就是 256 个字节，合并规则是在以英文为主的语料上统计出来的。中文几乎没参与训练，所以这些字节很少被合并，一个汉字常被切成 2~3 个 token。
3. 上面第 1 个 token`b'\xe6\x88'` 只有`我` 的前两个字节，单独解码时不是合法 UTF-8，`decode` 只能输出替换字符`�` 。
4. 把整串 token 拼起来字节就完整了，所以`tokenizer.decode(integers)` 能正确还原`我丢了一部苹果手机` 。
顺带一个结论：9 个汉字变成 19 个 token，说明 GPT-2 词表对中文极不高效（英文通常 1 词≈1~2 token）。做中文任务应该换`o200k_base` /`cl100k_base` ，或直接用 Qwen、DeepSeek 这类中文优化的分词器。
